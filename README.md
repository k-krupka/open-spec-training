# Overview

This is a course to teach and learn the OpenSpec technology.

We believe in spec drive development and agentic way of doing things.

The intent as a code is the way to go.

# Audience

All people who are interested in agentic way of working. It doesn't matter if this is a feature to be implemented, or a problem to be solved. What matters is the fact that we document and store the decisions. And OpenSpec is a perfect tool to do this...
