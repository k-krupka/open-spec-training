## Demo: add an email with an underspecified request

Start with the simple page and submit the [email request](./30-add-email-to-the-page.prompt.md) without supplying an address. Let the assistant ask a follow-up or show the assumption it makes; the example page uses a fictional address to make the assumption visible.

### Ask the audience

- What information is missing from the request?
- Should the assistant ask a question, use a clearly labeled placeholder, or invent a value?
- What would make the result acceptable, and how would a reviewer know?

### Expected takeaway

The issue is not that an assistant always needs a long prompt. The issue is that an unrecorded assumption can look like an approved requirement. A suitable clarification would ask which email address to display and whether it should be a clickable `mailto:` link. Do not treat the example address as real user data.
